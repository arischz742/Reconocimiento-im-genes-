# Clasificador de imágenes con Python

## Descripción
Proyecto desarrollado en Python para reconocer y clasificar imágenes mediante aprendizaje automático.

## Requisitos
- Python 3
- OpenCV
- NumPy
- Scikit-learn

## Instalación
Instalar las librerías necesarias con:

pip install -r requirements.txt

## Ejecución
Ejecutar el programa con:

python reconocimiento.py

## Banco de imágenes
Contiene las imágenes utilizadas para entrenar y probar el clasificador.
